### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Kasper166/Rubiks-Cube-Solver.git
   cd Rubiks-Cube-Solver
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```
